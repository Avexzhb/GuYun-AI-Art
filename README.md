# Run and deploy your AI Studio app (Finish all the design with Google AI Studio in 30 minutes and upload to Github)

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1CC7FYJpvnn_kNgZpj0GvIh1UuNRTWR5w

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
